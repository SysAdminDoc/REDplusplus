Command Line

  RED+.exe [-silent] -path "C:\target" [-path "D:\other" ...] [options]

  Options:
    -path <dir>        Scan root. Repeat for multiple roots. A bare path also works.
    -delete, -yes      Scan and delete in one shot (alias for -silent).
    -dryrun            Scan and report only; never delete.
    -emptyfiles        Also delete standalone zero-byte files.
    -mode <mode>       recycle | direct | move | simulate.
    -moveto <dir>      Required with -mode move; must be an absolute path.
    -minage <hours>    Override minimum directory age for this run.
    -maxdepth <n>      Override maximum scan depth for this run (-1 = infinite).
    -gitignore         Respect .gitignore rules for this run.
    -no-gitignore      Ignore .gitignore rules for this run.
    -mft               Try the MFT turbo scan for this run (administrator required).
    -no-mft            Disable the MFT turbo scan for this run.
    -hidden            Include hidden directories for this run.
    -ignore-hidden     Ignore hidden directories for this run.
    -system            Include system directories for this run.
    -ignore-system     Ignore system directories for this run.
    -lockout           Force report-only mode (no deletions) for this run.
    -no-lockout        Override a config-level lockout for this run.
    -parallel <n>      Parallel subdirectory scan threads (2-16, 0=serial).
    -exclude <name>    Per-run directory ignore filter (repeatable).
    -protect <name>    Per-run directory protect filter (repeatable).
    -export <file>     Write results to .txt, .csv, .json, .ps1, or .html.
    -json              Emit NDJSON: one meta record, then result records.
    -quiet             Suppress stdout/stderr; use the exit code and optional log.
    -log <file>        Write a timestamped run log.
    -undo [manifest]   Restore from the protected undo store.
    -profile <name>    Run a saved profile (other options still override).
    -saveprofile <name> Save the current options as a named profile and exit.
    -listprofiles      List saved profiles and exit.
    -deleteprofile <name> Delete a saved profile and exit.
    -eventlog          Write a summary event to the Windows Application Event Log.
    -classic           Open the legacy Windows Forms GUI instead of the WPF shell.
    -help, -version    Show help or version.

Preview a cleanup without touching anything:

RED+.exe -path "D:\Shares" -dryrun -json

Run from Task Scheduler and write a log:

RED+.exe -silent -path "\\server\share\folder" -log "cleanup.log"

Scan and delete with explicit intent:

RED+.exe -delete -path "D:\Shares\Home" -mode recycle -log "cleanup.log"

Save and reuse a profile for scheduled tasks:

RED+.exe -saveprofile nightly -path "D:\Shares" -mode recycle -emptyfiles
RED+.exe -silent -profile nightly -log "cleanup.log"

Speed up a network share scan with parallel enumeration:

RED+.exe -silent -path "\\server\share" -parallel 8 -log "cleanup.log"

Restore the previous deletion run:

RED+.exe -undo -log "restore.log"

Undo manifests are stored under the current user's protected LocalAppData folder. The last 5 manifests are kept. A raw manifest file path is treated as an explicit legacy restore and is constrained to the current user's safe profile boundary.

Exit Codes

  • 0 Success, or simulate/dry-run found nothing.
  • 1 Error, invalid argument, failed deletion, or failed undo.
  • 11 Simulate/dry-run succeeded and found empty directories or files.

The older -autosearch switch still opens the GUI and starts a search for the supplied path. Use -silent or any -path argument for true headless mode.
